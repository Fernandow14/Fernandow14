# 📂 Projetos em Destaque

### 📊 [Dashboard Analítico de Vendas — Power BI](https://github.com/Fernandow14/power-bi-sales-dashboard)

Projeto de Business Intelligence desenvolvido a partir de uma base simulada de vendas.

### Tecnologias utilizadas

- Power BI
- Power Query
- DAX
- Excel
- Modelagem Dimensional

### Principais etapas

- Ingestão de dados
- ETL com Power Query
- Criação de camada de staging
- Modelagem dimensional
- Construção de Star Schema
- Desenvolvimento de medidas DAX
- Criação de KPIs
- Construção de dashboard executivo
- Análise de produtos, clientes, vendedores, regiões, canais e status de vendas

### Alguns indicadores desenvolvidos

- Receita Total
- Ticket Médio
- Quantidade Vendida
- Vendas Concluídas
- Taxa de Cancelamento
- Meta por Período
- Percentual de Atingimento
- Ranking de Vendedores

### Principais análises

O projeto permitiu identificar:

- concentração de receita nos principais produtos;
- desempenho comercial por região;
- participação dos canais de venda;
- comportamento de clientes Pessoa Física e Pessoa Jurídica;
- vendas concluídas, pendentes e canceladas;
- desempenho dos vendedores em relação às metas.

📌 *Projeto desenvolvido com base simulada para fins de estudo e portfólio.*
